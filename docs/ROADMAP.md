# 分阶段交付

0.8.0-alpha.1 增加独立续聊工作区下拉框、默认选择、刷新与主动未分组；目录及原生分组持久写入，记忆范围独立，工作区不可用时明确拒绝。新接口向后兼容旧调用。

0.7.0-alpha.1 已实现历史页直接新建人格、本地清理结构化思考/工具/附件、自动分片导入全部会话并提交单个归档、分片重试与整包去重，以及离线预处理 CLI。记忆提取和续聊仍在导入完成后按需开始，不在导入时调用模型。

0.6.0-alpha.1 已实现人格 MEMORY/PROFILE、项目 SUMMARY、独立项目记忆子目录、旧目录迁移、可重建索引、关键词筛选后加载正文，以及模型 index/read 分页工具。

0.5.0-alpha.1 已将人格切换移到顶部「对话 / 轨迹 / 人格」并展示简介，记忆改为模型自动保存和更新，取消用户待确认流程及逐条过期时间表单。下方 0.2 / 0.3 的候选审阅描述为当时行为，现由自动决策替代。

## 第一阶段：独立插件与明确记忆

已实现：独立 npm 包与 Cordis bundle、Web/Desktop 共用 Client、人格模板、新建与编辑、同会话下一轮切换、明确记忆保存与纠正、人格与项目过滤、中文关键词召回、本地 Markdown、版本检查、跨进程写锁、内容遗忘，以及基于真实 AgentLoop 的无密钥测试。

需要用户实际安装环境验收：Desktop 原生安装窗口、不同屏幕和主题的交互体验、不同操作系统文件系统行为。当前自动化验证不等于已经完成 Desktop 实机验收。

## 第二阶段：持续学习与行为验证

已实现（0.2.0-alpha.1）：从新增的原始用户消息提取偏好，区分显式意图、临时要求和推测；候选审阅、独立证据计数、锁定、过期、冲突与来源时间比较；持久任务队列、处理游标、所有者租约、去重与失败重试；人格核心保持用户控制，表达习惯通过偏好记忆演化。提供绑定当前人格与项目的模型记忆工具。

已实现项目校验工具，执行用户配置的工具调用并根据真实退出码提供通过、失败、未执行、受阻四种状态。覆盖生成中切换、排队输入、热重载、队列恢复和压缩后的记忆补充。使用方式与限制见 [第二阶段说明](LEARNING.md)。Desktop 实机安装与真实模型提取质量仍需验收。

## 第三阶段：历史导入与语义召回

已实现（0.3.0-alpha.1）：DeepSeek mapping/fragments、ChatGPT mapping/current_node、通用 messages JSON 和角色标记 Markdown；对话分支与原文分页预览；按需分段提取、取消与检查点恢复、摘要汇总；可编辑的人格草稿、新建人格、合并所选分支及分别选择目标人格；来源去重与原始时间比较，导入记忆始终需要审阅。

新增原生 Harness 续聊：创建独立会话并导航打开，保留历史用户/助手正文、工作目录、模型和能力预设；长历史保留全文记录，模型使用受控摘要与近期片段，提供关联归档查找工具。建会话重试去重，通过真实 JSONL 存储重启后继续发送消息验证。可选 Ollama / embeddings 兼容接口实现范围过滤后的向量召回与关键词融合，异常回退关键词。格式和实际限制见 [导入说明](IMPORT.md)。

## 后续兼容性工作

已交付界面调整（0.4.0-alpha.1）：侧栏独立管理页、会话内人格选择与摘要、独立模型和项目选择、无源会话历史提取与续聊，以及原生下拉选项的深浅色配色修复。管理页的人格选择不改变会话选择。

更多真实平台样本适配、ZIP/HTML 与附件迁移；真实模型提取质量评估和 Desktop 安装验收；项目移动和 Git worktree 标识统一；按人格主动共享的记忆；备份导出和归档管理；更完整的跨文件事务与掉电恢复；无障碍和移动端交互。每个新阶段必须更新实际能力说明与版本，不将规划中的能力标成已完成。
